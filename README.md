# Армянский тренажёр

**Приложение:** https://zhannavdavydova.github.io/armenian-trainer/

Карточки для заучивания армянских слов: RUS → ARM и ARM → RUS, проверка голосом через Gemini (бесплатный ключ), без интернета — самопроверка. Интервальное повторение, уровни (30 слов на уровень), серия и рекорд, словарь, резервная копия прогресса в закрытый gist.

- `words.json` — словарь (`hy` — армянский, `ru` — перевод). Источник слов — заметка «Армянский» в Apple Notes.
- `app.js` — вся логика, `index.html` — интерфейс, `sw.js` — работа без интернета.

Обновление: правка файлов → `git push` → телефон подтягивает новую версию при следующем открытии с интернетом.
